# Info Guide 2005

This directory preserves the **Info Guide 2005** project developed for the PC World Romania / IDG Romania CD environment.

The archive includes both the **original CD material** and the **Visual Basic 6.0 source code**, together with a separate collection of historical executable builds produced during development.

## Preserved files

- `CD_InfoGuide (05.05.2005).zip` — preserved Info Guide CD build dated 05.05.2005.
- `CD_info_guide (original).zip` — original archived Info Guide CD material.
- `Info Guide 2005 src.zip` — preserved Visual Basic 6.0 source code of Info Guide 2005.
- `versions.zip` — **36 historical executable versions/builds** of the Info Guide application.

## About `versions.zip`

The 36 executable versions were originally preserved together with the CD material. They were removed from the CD ZIP archive only for repository-size reasons.

Keeping all of these executables inside the CD archive caused the ZIP file to exceed the **25 MB GitHub upload limit** applicable when the archive was added to the repository. To preserve the files without discarding any of the historical builds, the 36 executables were therefore placed separately in:

```text
versions.zip
```

This separation is purely an archival and repository-management decision. The files belong to the same Info Guide 2005 development history and should be considered part of the preserved project.

## Historical note

The multiple executables are not redundant replacements of the final program. They preserve intermediate and alternative compiled states produced during development and therefore provide a record of the application's evolution before the final CD version.

Together, the files in this directory preserve:

```text
Info Guide 2005
    |
    +-- original CD material
    |
    +-- final/preserved CD build
    |
    +-- Visual Basic 6.0 source code
    |
    +-- 36 historical executable builds
```

The directory should therefore be regarded as a compact preservation package for both the **released application** and its **development history**.
